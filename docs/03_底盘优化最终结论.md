# 底盘优化最终结论（重点）

## 修改位置（用户反复确认，勿再错）
- **修改的是「底盘上表面」**（法兰盘朝向筒体那一面，z=2 的环形面）。
- **内壁（内孔）绝对不动**；齿圈、止口、法兰下表面也不动。
- （曾两次搞错：一次改了内孔渐变壁厚、一次做了内厚外薄，都被纠正。）

## 变薄方向（用户确认）
**由外到内逐渐变薄**：法兰外缘（螺栓带）最厚 2.0 → 向内（靠近筒体）逐渐减薄 → 筒壁 0.30。

## 三段式（用户认可"三段式可以"）
| 段 | 半径 | 厚度 |
|---|---|---|
| C 螺栓压紧带（外） | R17.0 ~ R20.0 | 2.00 等厚 |
| B 锥面/圆弧过渡 | R10.5 ~ R17.0 | 2.00 → 0.85 |
| A 根部（接筒壁） | R10.31 ~ R10.5 | 0.85 → 0.30（R0.5 圆角） |

## 过渡形态（用户要求：中间不要直角，用平缓弧度）
三段式中间的直线锥改成平滑弧度，可选：
| 方案 | 参数 | 最大斜率 | 加工 |
|---|---|---|---|
| 直线锥 | **8°~12°（推荐 10°）** | 10° | 车刀一次走刀 |
| **单圆弧（推荐）** | **R19**（起弧于 R17.0/z2.000 相切，落到 R10.5/z0.85） | 中部~9°、根部~19° | R0.8 刀片一刀过 |
| S 形双圆弧（最优） | R25×2 相切 | ~5° | 一刀连续走 |

圆弧推导：单圆弧从 (17.0, 2.000) 相切起弧落到 (10.5, 0.85)：
```
6.5² + (R − 1.15)² = R²   →   R = 18.94 ≈ 19
圆心 = (17.0, 2.000 − 19) = (17.0, −17.0)
```

## 角度取值范围（底盘上端）
- 直线锥 8°~12°（推荐 10°）；圆弧 R18~R20（推荐 R19）；S 形 R25×2。
- <8°：外缘太厚减重不够；>12°：根部刚度突变应力上升。
