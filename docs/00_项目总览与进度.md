# 项目总览与当前进度

## 项目目标
为国产精密谐波减速器（对标绿的谐波 / HD）生成柔轮、刚轮的 SolidWorks 一键建模能力，
并完成 SHD-08 柔轮的精细化设计（齿形、壁厚、底盘斜度、公差）。

## 已完成的成果

### 1. 齿形（无公切线全光滑双圆弧 P 齿 / S 齿）
- 柔轮 z=200、刚轮 z=202（速比 100）
- 最终模数 **m = 0.104**（曾用 0.1016 / 0.105 / 0.103，最终定为 0.104）
- 详见 `docs/01_齿形设计标准.md`

### 2. 完整系列模型（速比 100）
- SHD-08 / 11 / 14 / 17 / 20 / 25 的杯型柔轮 + 刚轮
- 详见 `docs/06_尺寸系列参数.md`、`docs/08_模型文件清单.md`

### 3. SHD-08 柔轮精细设计（本次会话重点）
- 齿形、内孔、止口、底盘已逐步迭代多版
- 最终确认：**底盘上表面做斜度，内壁不动**
- 详见 `docs/03_底盘优化最终结论.md`

### 4. SolidWorks 一键 VBS 宏
- 多个 .vbs 脚本，附在 `scripts/`
