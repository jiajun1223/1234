# 精度与公差标注惯例

| 面 | 要求 |
|---|---|
| 安装端面 | 平面度 0.01，Ra1.6，0°（不许斜度） |
| 内孔止口 | H7，圆柱度 0.01，0°（直圆柱），深 1.31 |
| 中空孔 | H7，Ra1.6，0° |
| 螺栓孔 | 垂直度 0.05，孔口 0.3×45° 倒角 |
| 齿圈工作面 | Ra0.8 |
| 外圆 | h9 |
| 端面跳动 | 0.015 |
| 止口同轴度 | Ø0.02 |

## 结构尺寸（SHD-08 最终）
- 外形 Ø40 × 12
- 止口 Ø30.2 × 深 1.31（底部）
- 内孔 R10.006（Ø20.012）贯穿
- 筒体 OD R10.306（Ø20.612），z 2~8，壁厚 0.30
- 齿圈 z 8~12，200 齿
