# 齿形设计标准（无公切线全光滑双圆弧 P 齿 / S 齿）

## 硬性规则（必须严格遵守）
1. **单齿**：齿顶段为向外凸出的凸圆弧；从齿顶平滑过渡到齿侧、齿槽底，全程为向内凹陷的凹圆弧。
2. **整条齿廓连续光滑**，不允许出现任何平直公切线、平底直线段；圆周阵列后齿与齿槽首尾相连成连续 S 形波浪线。
3. **禁止渐开线齿形**；禁止齿顶内凹、齿根外凸的反向轮廓；齿根过渡圆角按应力优化取值，避免尖角。
4. 刚轮为内齿圈：齿槽（容纳柔轮齿顶）为凹圆弧，齿顶（朝圆心的齿尖）为凸圆弧。

## 单齿 S 形曲线公式（建模用）
设齿根半径 R_root、齿顶半径 R_tip、齿高 H = R_tip − R_root、单齿角距 TH_P = 2π/z：

```
r(s) = R_root + H · (1 + cos(π·|s|)) / 2     s ∈ [−1, 1]
ang(s) = s · TH_P / 2
点 = ( r·cos(ang), r·sin(ang) )
```

- 柔轮齿放在角度 k·TH_P；刚轮齿放在 (k+0.5)·TH_P（错开半个齿距，使柔轮齿顶落入刚轮齿槽）。
- 每齿采样 **24 点**，整圈 = 24×z 个点，最后一点闭合回第一点。
- 用 `CreateSpline`（样条）生成整圈齿廓，一次性挤出。

## 建模流程
1. 画 1 个单齿轮廓（约束完整尺寸）；
2. 圆周阵列生成整圈齿圈（实为：把整圈样条一次生成）；
3. 柔轮：旋转凸台生成杯体 → 齿圈挤出 → 内孔切除 → 螺栓孔；
4. 刚轮：法兰挤出 → 齿圈体挤出 → 内齿贯穿切除 → 安装孔。
